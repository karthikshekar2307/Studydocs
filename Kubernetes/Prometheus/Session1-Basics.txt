Terminology
- Monitoring: collecting and recording activity
- Alert: outcome of alerting rule in prometheus,sent from prometheus to alert manager
- Alert manager: Takes in alert from Prometheus server. Do pricessing on collected data and then send notification as per defined process.
- Target: Whose metrics are to be monitor
- Instance - Endpoint you can scraape is called instance
- Job - Collection of target/instance with same purpose

Prometheus metric types
- counter - A counter is a cumulative metric that represents a increasing counter whose value can only increase or be reset to zero on restart (ex - counter to represent the number of requests served, tasks completed or errors)
- gauges - A guage is a metric that represents a single numerical value that can arbitrarily go up and down
- History metrics  
- Summary metric - to calcualte average of something. Summary metric is used to calculate quantiles over a sliding time window. It provides information about the distribution of values, including quantiles (percentiles) and a sum of observations.
The quantiles show the values below which a certain percentage of observations fall. we get following component - count, sum and quantiles
Count - Number of times event has occurred
sum - Total size of all the events
Quantiles - values representing specific percentiles
- Histogram metric - used to calculate the distruibution of values into buckets. It provides insights into how data is distributed across various value ranges. it provides - count, sum, and bucket values
